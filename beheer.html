Eigen pagina of script

Upload een HTML-pagina met JavaScript of een los JavaScript-bestand. Bezoekers openen uw upload via ‘Zie openstaande bedragen’. Gebruik één bestand; afbeeldingen en andere bestanden moeten via volledige URL’s worden geladen.

Python (.py) wordt niet uitgevoerd. Cameratoestemming moet in uw eigen code duidelijk aan de bezoeker worden gevraagd.
